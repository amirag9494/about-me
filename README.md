# ⚡ Amir Hossein Aghajani | Personal Portfolio & Resume Card

A modern, highly polished, and fully accessible (A11y) portfolio page built using **HTML5** and **CSS3**. Designed to showcase core technical milestones, a dynamic skills roadmap, and continuous learning progress in Python backend development and web technologies.

## ✨ Key Features & Highlights

* **Semantic HTML5 Architecture:** Built with proper landmark elements (`<header>`, `<main>`, `<section>`, `<footer>`) for maximum accessibility and clean document flow.
* **Structured Data Tables:** Features a comprehensive skill and progress matrix complete with `<caption>`, `<thead>`, explicit `scope` attributes, and custom status badges.
* **Accessible & Interactive Forms:** Fully optimized form elements with explicitly associated `<label>` tags, custom focus rings, and smooth validation states.
* **Modern CSS3 Design System:** Styled using custom CSS properties (variables), subtle glassmorphism card elevations, smooth hover transformations, and responsive media queries.

## 🛠️ Tech Stack & Current Roadmap

* **Frontend:** HTML5, CSS3 (Flexbox, Grid, Custom Properties)
* **Backend / Scripting:** Python (Intermediate / Active Learning)
* **Tools & Environment:** Linux, Command Line, Git & GitHub
* **Languages:** English (Advanced, IELTS Target 7.5+)
