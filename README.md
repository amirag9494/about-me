# Personal Portfolio & Resume Card

A clean, semantic, and accessible (A11y) HTML5 portfolio page designed to showcase core development milestones, technical skills, and continuous learning progress.

## Features
- **Semantic HTML5 Structure:** Uses proper landmark elements (`<header>`, `<main>`, `<section>`, `<footer>`).
- **Data Tables:** Structured skill matrix with `<caption>`, `<thead>`, and `scope` attributes for screen readers.
- **Accessible Forms:** Explicitly associated `<label>` elements with form inputs.
- **Minimalist CSS:** Styled using modern layout properties within a compact stylesheet.
